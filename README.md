# spear-marketing-site
Static site for https://spear-marketing.com, served by GitHub Pages from `main` (custom domain in `CNAME`).

- `index.html` – the single page.
- `assets/` – logo, favicons, hero images, self-hosted fonts (OFL licences included).

Edit via a branch and PR, merge to `main`, and Pages republishes. This repo is public: never commit secrets or private files.
